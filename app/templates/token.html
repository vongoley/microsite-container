在终端执行以下命令，将 Token 配置到 Claude Code skill：

mkdir -p ~/.config/html-container
printf 'API_KEY={{ tokens[0].token }}\nBASE_URL=\n' > ~/.config/html-container/credentials.env

配置完成后，在任何工作区使用 Claude Code 即可通过 skill 自动上传文件。
